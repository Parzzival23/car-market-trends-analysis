# Car Market Trends Analysis with CarDekho Data

## Project Overview

This project analyzes used-car market data from CarDekho
to identify pricing patterns, resale trends and relationships
between vehicle characteristics and selling price.

## Objectives

- Analyze used-car market trends
- Study factors associated with selling price
- Compare fuel and transmission categories
- Analyze vehicle age and mileage
- Study depreciation and resale percentage

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Findings

- Present Price has a strong positive association with Selling Price (r = 0.876)
- Car Age has a negative association with Selling Price (r = -0.234)
- Kms Driven has almost no linear association with Selling Price (r = 0.029)
- Diesel vehicles have the highest average resale percentage
- Automatic vehicles have higher average selling prices in this dataset

## Dataset

299 unique records after removing duplicate records.
